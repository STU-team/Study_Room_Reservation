## 二、记录规范

1. 每完成一次任务追加一条记录，不覆盖、不删除历史行。
2. 任务编号沿用分工文档（A-1 ~ A-8 / B-1 ~ B-8）。
3. "产出"填写仓库内的相对路径；"提交"填写提交信息主题或短哈希。
4. 涉及契约变更、接口调整的，在内容中注明 `CONTRACT-CHANGE`。
5. 只记录实际完成的工作，并按实际完成人署名；评审、待办写在第四节，不写进记录表。
