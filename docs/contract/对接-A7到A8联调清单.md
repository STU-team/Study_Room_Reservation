## 一、入口与初始化

```java
ServiceFactory.configure(Path.of("data"));   // 默认就是 data/，改目录时调用一次
AuthService auth = ServiceFactory.getAuthService();
SeatService seats = ServiceFactory.getSeatService();
ReservationService reservations = ServiceFactory.getReservationService();
```

- 三个 Service 都是单例，重复获取不会再建表。
- 首次装配时自动建七张 CSV 表头并写入示例数据（仅当表为空），异常统一抛 `BusinessException("DATA_INIT", …)`。
- 程序入口先 `configure`，再取 Service；**不要**在构造窗体时取，避免数据目录未定位。

## 二、界面动作 → Service 方法

| 界面动作 | 调用 | 返回 | 备注 |
|---|---|---|---|
| 登录 | `auth.login(username, password)` | `User` | 登录态自己存（`User` 对象放窗体字段），A 侧无 `currentUser()` |
| 退出登录 | `auth.logout()` | 无 | 空实现，清掉自己保存的 `User` 即可 |
| 座位总览 | `seats.listAllSeats()` | `List<Seat>` | 含四种状态，适合做座位图/表格 |
| 按号查座位 | `seats.findByNo(seatNo)` | `Seat` | 不存在抛 `SEAT_NOT_FOUND` |
| 查询某时段可用座位 | `reservations.listAvailableSeats(date, start, end, typeName)` | `List<Seat>` | `typeName` 传 `null` 表示全部区域 |
| 我的预约列表 | `reservations.listReservations(studentId)` | `List<Reservation>` | 按开始时间倒序，直接填 `JTable` |
| 全部预约列表 | `reservations.listAllReservations()` | `List<Reservation>` | 管理端用，同样倒序 |
| 在座名单 | `reservations.listSeated()` | `List<CheckinRecord>` | 只返回已签到未签退的记录（`actualEnd` 为空） |
| 预约 | `reservations.reserve(seatNo, student, date, start, end)` | `Reservation` | `student` 传登录返回的对象即可，内部按学号查档案 |
| 取消预约 | `reservations.cancelReservation(resNo)` | `Reservation` | 仅 `BOOKED` 且未过截止时间 |
| 签到登记 | `reservations.signIn(resNo)` | `Reservation` | 立即写签到记录，座位转 `OCCUPIED` |
| 签退 | `reservations.signOut(resNo, actualEnd)` | `CheckinRecord` | `actualEnd` 为 `LocalTime`，早于开始时间会被拒 |
| 爽约扫描 | `reservations.handleNoShow(LocalDateTime.now())` | `int` 处理条数 | 由 `javax.swing.Timer` 触发：启动一次 + 每 60 分钟一次 |
| 转维修 / 恢复 | `seats.updateSeatStatus(seatNo, status)` | 无 | `OCCUPIED → AVAILABLE` 会被拒（须先签退） |

**座位区域名**：`Seat` 的字段名是 `roomName`，实际存的是 `seat_types.csv` 的 `typeName`（靠窗区、沙发区）。取区域用 `seat.getRoomName()`，不要找 `getTypeName()`。

## 三、异常码 → 建议提示文案

异常都是 `com.studyroom.service.BusinessException`，用 `e.getCode()` 判分支、`e.getMessage()` 兜底显示。

| 异常码 | 触发场景 | 出现位置 | 建议界面提示 |
|---|---|---|---|
| `PARAM` | 必填项为空、结束时间不晚于开始、签退时间早于开始、日期超出预约窗口 | 全部方法 | 提示具体字段：「请选择日期与时段」「结束时间需晚于开始时间」「只能预约 7 天内的日期」 |
| `CREDIT_LOW` | 学生信用分 < 80 | `reserve` | 「信用分低于 80，暂不能预约，请联系值班管理员」 |
| `SEAT_UNAVAILABLE` | 座位不是 `AVAILABLE` | `reserve` | 「该座位当前不可预约（维修中/使用中/已被锁定）」 |
| `SEAT_CONFLICT` | 同座位同时段已有 `BOOKED`/`CHECKED_IN` 预约 | `reserve` | 「该座位在所选时段已被预约，请换座位或换时段」 |
| `SEAT_NOT_FOUND` | 座位号在 `seats.csv` 中不存在 | `findByNo`、`reserve`、签退内部 | 「座位不存在，请核对座位号」 |
| `SEAT_IN_USE` | 对 `OCCUPIED` 座位直接改 `AVAILABLE` | `updateSeatStatus` | 固定文案「座位使用中，须先办理签退」——须原样显示，契约要求 |
| `STATE` | 状态不允许该操作（重复签到、取消已签到、签退未签到） | `cancelReservation`、`signIn`、`signOut` | 「当前状态不支持该操作，请刷新后重试」 |
| `DEADLINE` | 已过签到截止时间（开始 + 15 分钟） | `cancelReservation`、`signIn` | 「已超过签到截止时间（预约开始后 15 分钟）」 |
| `STUDENT_NOT_FOUND` | 学号不在 `students.csv` | `reserve`、扣分内部 | 「学生档案不存在，请先由管理员建档」 |
| `AUTH_FAILED` | 用户名不存在或密码不符 | `login` | 「用户名或密码错误」 |
| `DATA_INIT` | 数据目录建表失败 | 首次取 Service | 「数据初始化失败：」+ `getMessage()` |
| `NOT_FOUND` | 预约号不存在 | 取消/签到/签退 | 「预约记录不存在，请核对预约号」 |

处理惯例：`catch (BusinessException e)` 用 `JOptionPane` 弹提示，`AUTH_FAILED`/`PARAM` 留在当前页，`STATE`/`DEADLINE` 提示后刷新列表。除 `DATA_INIT` 外都不该弹堆栈。

## 五、A-8 联调验收清单

- [ ] 三种角色都能登录，登录后能取到用户名与角色，错误密码提示「用户名或密码错误」。
- [ ] 座位总览显示四种状态且颜色/图标可区分；维修中座位不可选。
- [ ] 查询可用座位：换区域、换时段结果随之变化；已被预约的时段查不到该座位。
- [ ] 预约成功：座位转「已预约」，预约列表新增一条 `BOOKED`，显示签到截止时间。
- [ ] 信用分 70 的学生预约被拒，提示信用分不足，座位状态不变。
- [ ] 签到成功：预约转 `CHECKED_IN`、座位转「使用中」，在座记录出现且结束时间为空。
- [ ] 签退成功：预约转 `CHECKED_OUT`、座位回到「可用」；超时返回 `penalty=1` 并新增一条 `LATE_CHECKOUT` 流水。
- [ ] 爽约扫描：把某条 `BOOKED` 的预约等到超过截止时间，手动点一次扫描，预约转 `NO_SHOW`、扣 5 分、座位释放。
- [ ] 对使用中座位点「转维修」被拒，提示须先签退；签退后再转维修成功。
- [ ] 关闭程序重开，上述所有改动仍在（CSV 已落盘）。
