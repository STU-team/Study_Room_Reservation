3. **画 4 类关系**（缺一不可）：
   - 关联：3 个参与者分别连各自的 8 个主用例（已画好，保留）；

   - 泛化：顾客、前台、管理员 ─▷ **用户**（抽象参与者，空心三角箭头指向“用户”）。
4. **写 8 条用例叙述**，每条按指导书模板：

   | 字段 | 写法 |

   | 用例简述 | 一句话，与上表一致 |
   | 前置条件 | 例如“顾客已进入查询界面” |
   | 后置条件 | 例如“系统返回可用房间列表” |
   | 基本流程 | 3~6 步，编号写 |

   | 被包含 / 被扩展 | 按图填，没有写“无” |
